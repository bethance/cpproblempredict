How ratings are produced

  • Official first: if Codeforces has rated the problem, that number is shown as-is.
  • Unrated Codeforces problems: a Ridge regression blended with gradient-boosted trees, trained on rated problems. Inputs: solve count (log), standing among the contest's problems, position (A, B, C…), contest type, contest age and tags.
  • AtCoder: AtCoder Problems' difficulty is mapped onto the Codeforces scale by quantile matching. No problem is rated on both sites, so this is approximate and the range is wide.
  • CSES: no usable data source, so no estimate.

Accuracy

Training reports error measured on contests the model never saw (grouped cross-validation). The typical error is shown on each estimate; run python train.py to retrain on fresh data.
